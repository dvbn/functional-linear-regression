# Functional Linear Regression with Functional Response

David Benatia, Marine Carrasco and Jean-Pierre Florens. *Journal of Econometrics*
201(2), 2017, pp. 269–291.

[Published paper](https://doi.org/10.1016/j.jeconom.2017.08.008) · [Author manuscript](https://www.dropbox.com/scl/fi/apqcrak7pjrcq7mujguza/functional-linear-regression-author-manuscript-2017-02.pdf?rlkey=bp2a1tcs323pf0xgo4g8j6sxc&dl=0) · [Author website](https://www.davidbenatia.com/research/)

MATLAB code for functional linear regression with functional responses,
instrumental-variable estimation, cross-validation and out-of-sample prediction.

## Usage

Open this folder in MATLAB and run:

- `Example.m` for an illustrative simulation.
- `Simulation.m` for the simulation study.
- `Application.m` for the electricity-consumption application using the included `DATA.mat`.

The application uses Optimization Toolbox. The simulations use Statistics and
Machine Learning Toolbox and Parallel Computing Toolbox. Function help is
included in the `.m` files. Third-party helper comments and credits are retained.

The [original replication ZIP](https://www.dropbox.com/scl/fi/zjla8shlxlfq67uae7w6s/functional-linear-regression-original-replication.zip?rlkey=o55st42hvruszvbtqh11sru23&dl=0) is also available on Dropbox.
